# Security

This repository contains a calculation library. It does not operate accounts,
store birth records, or provide the hosted Bornsky API.

Do not post credentials, real birth records or other personal data in issues,
pull requests, examples or logs. Use synthetic inputs when reporting a bug.

For sensitive vulnerabilities, use GitHub's **Report a vulnerability** option
on the repository's Security tab when available. If it is not available, use
the contact route on [Bornsky](https://bornsky.app/en#api-partnership) to request
a private reporting channel; do not include exploit details or sensitive data
in that initial request. Ordinary numerical calculation bugs may be reported
as GitHub issues with a reproducible synthetic example.

Only the latest revision on `main` is maintained at present. There are no
long-term-support release branches or guaranteed response times. The hosted
service and this library have separate release lifecycles.
